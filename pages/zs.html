ZS Engine - ZS Script API

ZS Language: A natural programming language

A natural programming language removes barriers, no ASCII hacks, no null, no ASCII symbols. Instead, it's a part of Math. It uses Unicode symbols and uses Math rules & philosophy.

What's ZS?

ZS (Zentle Script) is a natural language scripting system designed for Psych Engine modding. It reads like English and uses mathematical symbols instead of ASCII operators. ZS scripts are transpiled to Lua and run within Psych Engine.

ZS is built on the principle that code should be readable and accessible to everyone, not just programmers. By using natural language keywords and mathematical symbols, ZS lowers the barrier to entry for mod creation.

ZS's Philosophy

  • Natural Language – Write code that reads like English sentences
  • Mathematical Notation – Use real math symbols: ×, ÷, −, ≠, ≤, ≥
  • Indentation-Based Blocks – No end clutter, just clean indentation
  • Noun Symbols – Variables are wrapped in < > for clarity
  • Curly Quotes – Strings use “ ” and ‘ ’ to avoid visual noise
  • No Unnecessary Symbols – No semicolons, no parentheses for function calls, no ASCII hacks

ZS Rules

  • Every ZS file must start with ! ZS-LUA
  • Variables are wrapped in < >: <health>
  • Strings use curly quotes: “Hello World”
  • Subtraction uses −, not -
  • Multiplication uses ×, not *
  • Division uses ÷, not /
  • Not equal uses ≠, not ~=
  • Less than or equal uses ≤, not <=
  • Greater than or equal uses ≥, not >=
  • Indentation defines block structure (no end keywords)
  • Property access uses read <property>
  • Property assignment uses change <property> to value
  • Functions use noun syntax: myFunc<arg1>, <arg2>
  • Events use colon: onCreate:, onUpdate<elapsed>:
  • Print uses colon: print: “text”
  • Debug print uses: print(debug): “text”
  • Library calls use colon: math: pi
  • Library imports: import math or import math as m
  • Custom libraries require import myLib
  • Comments use -/ for single line
  • Block comments use */- to open and /-* to close
  • No semicolons ; allowed
  • No Lua comments -- allowed
  • No straight quotes " or ' allowed
  • No function keyword – use events instead
  • No return keyword – use proceed or halt
  • No nil – use empty or null
  • No end – indentation handles block closure

What ZS banned

- (hyphen for subtraction) − (minus sign)

/ (slash) ÷ (division sign)
~= ≠
<= ≤
>= ≥
" ' (straight quotes) “ ” ‘ ’ (curly quotes)
-- (Lua comment) -/ (ZS comment)
function onCreate:, myFunc<arg>:
end Indentation (automatic)
return give or give back
return value give value or give back value
return nil give nothing
nil space (function arg only) or leave empty
; (semicolon) Not allowed
&& || ! and or not
++ += 1 or change <var> to read <var> + 1
-- (decrement) −= 1 or change <var> to read <var> − 1
