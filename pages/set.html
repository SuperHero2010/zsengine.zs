Set Operations

ZS supports standard mathematical set operations using Unicode symbols with support for both Western and Orient conventions.

Overview

ZS provides built-in set operations using standard mathematical notation. Sets are represented as Lua tables, and operations are transpiled to efficient Lua code.

ZS supports two mathematical conventions for set symbols:

  • Orient Convention (Default): ⊂ = Subset (allows equality), ⊆ = Equal Subset (no equality)
  • Western Convention: ⊂ = Proper Subset (no equality), ⊆ = Subset (allows equality)

Set Convention Flags

You can choose which convention to use by adding flags after ! ZS-LUA:

Flag Convention ⊂ Means ⊆ Means
! ORIENT (Default) Orient Math Subset (allows equal) Equal Subset (no equal)
! WESTERN Western Math Proper Subset (no equal) Subset (allows equal) 
! ZS-LUA
! WESTERN

onCreate:
    -/ Use Western convention

Note: Using both ! WESTERN and ! ORIENT in the same script will cause a transpiler error.

Examples

Orient Convention (Default)

! ZS-LUA
! ORIENT

onCreate:
    local <A> = {1, 2, 3}
    local <B> = {1, 2, 3, 4, 5}

    -/ ⊂ means subset (allows equal)
    if <A> ⊂ <B> then
        print: “A is subset of B”

    -/ ⊆ means equal subset (no equal)
    if <A> ⊆ <B> then
        print: “A is equal subset of B”

Western Convention

! ZS-LUA
! WESTERN

onCreate:
    local <A> = {1, 2, 3}
    local <B> = {1, 2, 3, 4, 5}

    -/ ⊂ means proper subset (no equal)
    if <A> ⊂ <B> then
        print: “A is proper subset of B”

    -/ ⊆ means subset (allows equal)
    if <A> ⊆ <B> then
        print: “A is subset of B”

Basic Set Operations

! ZS-LUA

onCreate:
    local <A> = {1, 2, 3, 4, 5}
    local <B> = {4, 5, 6, 7, 8}

    -/ Intersection: {4, 5}
    local <C> = <A> ∩ <B>

    -/ Union: {1, 2, 3, 4, 5, 6, 7, 8}
    local <D> = <A> ∪ <B>

    -/ Set Difference: {1, 2, 3}
    local <E> = <A> \ <B>

Element Checking

! ZS-LUA

onCreate:
    local <S> = {10, 20, 30, 40, 50}

    if 20 ∈ <S> then
        print: “20 is in the set”

    if 100 ∉ <S> then
        print: “100 is not in the set”

Complex Set Operations

! ZS-LUA

onCreate:
    local <A> = {1, 2, 3, 4, 5, 6}
    local <B> = {4, 5, 6, 7, 8}
    local <C> = {6, 7, 8, 9, 10}

    -/ (A ∩ B) ∪ C
    local <result> = (<A> ∩ <B>) ∪ <C>

    -/ (A \ B) ∩ C
    local <result2> = (<A> \ <B>) ∩ <C>

Complement

! ZS-LUA

onCreate:
	local <A> = {1, 2, 3, 4}
	local <B> = {3, 4, 5, 6}
	local <C> = ∁(<A>, <B>)
	-/ C = {5, 6} (elements in B not in A)

Helper Functions

These functions are automatically available in all ZS scripts for set operations:

Function Parameters Return Description
tableContains table, value Bool Check if value exists in table
tableIntersection A, B table Returns elements in both A and B
tableUnion A, B table Returns elements in A or B
tableComplement A, B table Returns elements in B but not in A (complement)
tableDifference A, B table Returns elements in A but not B
subsetEq A, B Bool Checks if A is subset of B (allows equality)
subsetStrict A, B Bool Checks if A is strict subset of B (no equality)
notSubsetEq A, B Bool Checks if A is not subset of B
supersetEq A, B Bool Checks if A is superset of B (allows equality)
supersetStrict A, B Bool Checks if A is strict superset of B (no equality)
notSupersetEq A, B Bool Checks if A is not superset of B
