Logic Operators

ZS uses mathematical logic symbols for clean, unambiguous logic operations.

Overview

ZS uses Unicode logic symbols instead of English keywords to avoid ambiguity. The and keyword is reserved for array access only.

Logic Operators

Symbol Name ZS Example Lua Equivalent
∧ Logical AND if <x> > 0 ∧ <x> < 10 then if x > 0 and x < 10 then
∨ Logical OR if <x> < 0 ∨ <x> > 10 then if x < 0 or x > 10 then
¬ Logical NOT if ¬<alive> then if not alive then
∀ For All ∀ <i> in <list> where <i> > 0 forAll(list, function(i) return i > 0 end)
∃ Exists ∃ <i> in <list> where <i> > 5 exists(list, function(i) return i > 5 end)

Rules

Rule Description
and is array separator only <i> and <j> of <matrix> → matrix[j][i]
∧ is logical AND if <x> > 0 ∧ <x> < 10 then
∨ is logical OR if <x> < 0 ∨ <x> > 10 then
¬ is logical NOT if ¬<alive> then
∀ is For All ∀ <i> in <list> where <i> > 0
∃ is Exists ∃ <i> in <list> where <i> > 5

Examples

Logical AND

! ZS-LUA

onCreate:
    local <x> = 5
    if <x> > 0 ∧ <x> < 10 then
        print: “x is between 1 and 9”

Logical OR

! ZS-LUA

onCreate:
    local <x> = -5
    if <x> < 0 ∨ <x> > 10 then
        print: “x is outside 0-10”

Logical NOT

! ZS-LUA

onCreate:
    local <alive> = true
    if ¬<alive> then
        print: “Player is dead”
    else
        print: “Player is alive”

For All

! ZS-LUA

onCreate:
    local <list> = {1, 2, 3, 4, 5}
    if ∀ <i> in <list> where <i> > 0 then
        print: “All elements are positive”

Exists

! ZS-LUA

onCreate:
    local <list> = {1, 2, 3, 4, 5}
    if ∃ <i> in <list> where <i> > 5 then
        print: “There is an element greater than 5”

Combined Logic

! ZS-LUA

onCreate:
    local <health> = 75
    local <shield> = 20
    if <health> > 0 ∧ <shield> > 0 then
        print: “Player is protected”
    else if <health> < 50 ∨ <shield> < 10 then
        print: “Player is vulnerable”
    else
        print: “Player is healthy”

Validation

Input Status Reason
if <x> > 0 and <x> < 10 then ❌ Error Use ∧ instead of and
if <x> > 0 ∧ <x> < 10 then ✅ Valid Logical AND
<i> and <j> of <matrix> ✅ Valid Array separator
