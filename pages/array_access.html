ZS Engine - ZS Script API

Array Access

ZS provides natural language array access using of and and keywords.

Overview

ZS uses natural language for array access instead of bracket notation []. The keywords of and and make array operations read like English sentences.

Syntax

ZS Syntax Lua Equivalent Description
<index> of <array> array[index] Single index access
<index1> of <index2> of <array> array[index2][index1] Nested access (right-associative)
<index1> and <index2> of <array> array[index2][index1] Multi-dimensional access
<a> of <f> and <b> of <g> g[b][f[a]] Mixed nested and multi-dimensional

Examples

Single Index

! ZS-LUA

onCreate:
    local <list> = {10, 20, 30, 40, 50}
    local <first> = <1> of <list>
    -/ first = 10

Nested Arrays

! ZS-LUA

onCreate:
    local <matrix> = {{1, 2}, {3, 4}, {5, 6}}
    local <value> = <1> of <2> of <matrix>
    -/ value = matrix[2][1] = 3

Multi-Dimensional Access

! ZS-LUA

onCreate:
    local <cube> = {{{1, 2}, {3, 4}}, {{5, 6}, {7, 8}}}
    local <value> = <1> and <2> of <cube>
    -/ value = cube[2][1]

Mixed Nested and Multi-Dimensional

! ZS-LUA

onCreate:
    local <A> = {10, 20, 30}
    local <B> = {40, 50, 60}
    local <M> = {<A>, <B>}
    local <result> = <2> of <A> and <1> of <M>
    -/ result = M[1][A[2]] = 30

Loop with Array Access

! ZS-LUA

onCreate:
    local <list> = {10, 20, 30, 40, 50}
    local <sum> = 0
    for <i> from 1 = 5 do
        change <sum> to <sum> + <i> of <list>
    print: “Sum is ” + read <sum>

Rules

Rule Description
of is right-associative <i> of <a> of <f> → f[a[i]]
and separates indices <i> and <j> of <k> → k[j][i]
Indices are 1-based Lua tables are 1-based by default
Nouns must be declared Use local, global, or change

Transpilation

ZS Lua
<i> of <list> list[i]
<i> of <a> of <f> f[a[i]]
<i> and <j> of <k> k[j][i]
<a> of <f> and <b> of <g> g[b][f[a]]
<a> and <m> of <f> and <b> and <n> of <g> g[n][b][f[m]][a]
